**[SplitsBugs](https://github.com/lotus-outlook-6/SplitsBugs)** &nbsp;—&nbsp; `Astro` `Firebase` `TypeScript`
A real-time expense splitting web platform for groups. Features automated balance recalculations, partial settlements, and role-based access control.

A serverless health screening system. It reads vitals over I²C from a pulse oximeter and evaluates risk using a Random Forest model running natively in the browser.

**[ProteoPredict](https://github.com/lotus-outlook-6/ProteoPredict)** &nbsp;—&nbsp; `Python` `Keras`
